# Windows 打印店专业书籍封面拼版与装订辅助系统 v2.1 (Flagship Edition)

专为快印店、打印店、图文广告公司、排版装订员以及个人出版设计的 Windows 桌面端辅助工具。输入书籍的**正面封面**和**背面封面**图片，系统将自动推算书脊厚度、处理装订工艺（平装胶订 / 精装硬皮包壳）、叠加裁切角线（Crop Marks）与折痕虚线，一键生成符合 1:1 印刷标准的高清 **A3 / A4 封面拼版图** (支持 300 DPI 高清 PNG/JPG 以及矢量 PDF 导出)。

---

## 🌟 旗舰版 (v2.1) 核心功能

### 1. 两种装订工艺支持 (平装胶订 vs. 精装包壳)
- **平装无线胶订 (Softcover)**：标准 3mm 出血，自动计算书脊厚度与折痕线。
- **精装硬皮包壳 (Hardcover)**：支持设置包边/折边宽度（15mm ~ 20mm）与压槽/沟槽宽度（6mm ~ 10mm），自动计算灰板纸厚度增加量。

### 2. 专业区分【封面用纸】与【内页用纸】
- **封面材质 (Cover Stock)**：200g/250g/300g/350g 铜版纸、哑粉纸、白卡纸、珠光纸、皮纹纸、157g+灰板纸等。
- **内页材质 (Inner Paper)**：70g/80g/100g/120g 双胶纸、轻型纸/蒙肯纸、道林纸等。

### 3. 书脊厚度智能推算计算器
- 输入内页总 P 数（页数）并选择内页纸张克重，系统自动通过公式 `(页数 / 2) * 纸张单叶厚度 + 装订胶层/灰板余量` 精准推算书脊厚度，并一键应用至拼版参数中。

### 4. 丰富全面的印前规格预设
- **打印纸张/版面规格**：A3 (420x297mm)、SRA3 (450x320mm)、A3+ (483x329mm)、A4、A2、B4、B3、8开 (420x285mm)、正度8开、4开、16开及自定义尺寸。
- **成品书籍规格**：A5、A4、B5、16开 (大度/正度)、32开 (大度/正度/大32开)、24开、20开、正方形 (210x210mm / 150x150mm) 及自定义尺寸。

### 5. 图像修饰、防白边与条形码生成
- **镜像自动出血 (Mirror Bleed)**：针对原图缺少出血位的情况，自动生成镜像模糊延伸背景，防止切纸出现白边。
- **条形码 / ISBN 生成器**：一键在封底右下角生成矢量/高清晰 ISBN 条形码与编号。
- **清晰度 (DPI) 智能检测**：导入封面图片时实时计算有效印刷 DPI，若原图低于 200 DPI 会自动弹出低清警告。
- **色彩与标题叠加**：支持亮度/对比度调节、书脊中文竖排/横排文字、封面标题与封底文字叠加。

### 6. 自定义配置模板管理 (User Presets)
- 提供系统的常用快印预设（如 A5胶订、16开胶订、A5精装包壳）。
- 支持将当前的装订工艺、纸张规格、出血与条码设置保存为**自定义名称的 JSON 模板**，方便下次一键调取或删除。

## 🖥️ 运行与开发环境

- **操作系统**：Windows 10 / Windows 11 / Linux
- **开发语言**：Python 3.8+
- **核心依赖包**：`Pillow`, `ReportLab`, `PyInstaller` (打包)

### 1. 本地启动运行

```bash
# 1. 安装依赖
pip install pillow reportlab

# 2. 启动图形界面应用
python main.py
```

### 2. 运行单元测试 suite

```bash
python -m unittest discover -s tests
```

## 📦 打包为独立 Windows .EXE 可执行文件

在 Windows 电脑上，无需安装 Python 环境即可将软件打包为独立运行的 `.exe` 可执行程序，方便直接部署在快印店电脑上。

### 打包步骤：

双击运行项目根目录下的 `build_exe.bat` 批处理脚本，或者在命令行中运行：

```bash
python build_exe.py
```

打包完成后，生成的可执行程序位于 `dist/BookCoverGenerator/BookCoverGenerator.exe`。
