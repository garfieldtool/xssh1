## 2. 📄 PDF 文件导入与页码提取选择

除图片格式（PNG, JPG, WebP 等）外，系统全面支持直接导入客户提供的 `.pdf` 矢量文档并提取任意页面作为封面：

1. **点击浏览选择文件**：在“正面封面”或“背面封面”选择 `.pdf` 文档。
2. **选择提取页码**：
   - **提取第 1 页**：作为正面封面（默认设为第 1 页）。
   - **提取最后一页**：设为 `-1` 即可自动渲染 PDF 的最后一页作为封底。
   - **提取自定义页**：输入具体页码（例如第 2 页，第 100 页）。
3. 系统按 300 DPI 矢量渲染提取该页，并实时同步更新拼版图！

## 4. 🏷️ 封面用纸与内页纸张材质参考

- **200g 铜版纸 / 哑粉纸**：轻薄软封面。
- **250g 铜版纸 / 哑粉纸 (标准胶订)**：快印店**最常用**无线胶订封面卡纸。
- **300g 铜版纸 / 哑粉纸 (厚封面)**：高质量厚实封面。
- **350g 铜版纸 / 哑粉纸**：超厚平装封面。
- **230g 白卡纸 / 灰底白**：名片及高挺度封面。
- **250g 粗皮纹纸 / 灰皮纸**：标书、合同、报告特种装订封面。
- **250g 珠光纸 / 艺术纸**：艺术画册、高端邀请函。
- **157g 铜版纸 + 2.0mm 灰板 (精装硬皮)**：精装硬皮包壳标准配纸。
- **157g 铜版纸 + 2.5mm 灰板 (精装硬皮)**：加厚精装硬皮包壳。

## 5. 📐 两种装订工艺 (平装胶订 vs 精装包壳)

切换不同装订方式，系统将自动调整拼版展开图的计算逻辑：

1. **平装无线胶订 (Softcover)**：
   - 包含：`封底 + 标准出血(默认3mm) | 书脊 | 封面 + 标准出血(默认3mm)`。
   - 生成标准的压痕/折痕虚线。

2. **精装硬皮包壳 (Hardcover)**：
   - 包含：`折边包边(默认15-20mm) + 封底 + 压槽沟槽(默认8mm) | 书脊(含灰板加厚) | 压槽沟槽 + 封面 + 折边包边`。
   - 自动加算精装硬皮压槽线与包皮折边包角区域。

## 6. 🧮 智能书脊厚度推算计算器

在 **【2. 页数厚度计算】** 页签中：
1. 输入书本内页总 **P 数（页数）**（例如：200P）。
2. 选择内页材质克重（例如：`80g 双胶纸`）。
3. 点击 **【推算并套用书脊厚度】** 按钮。
4. 系统按公式 `(P数 / 2) * 单叶厚度 + 胶层余量` 自动计算（如 200P 80g 双胶纸约为 10.3mm），并自动填入并刷新全套拼版！

## 7. 🎨 封面图片编辑、文字叠加与条形码生成

切换至 **【3. 图片修饰与条码】** 页签：

### 7.1 封面与封底图片色彩调节
- **亮度 (Brightness) 滑块**：0.5 (暗) ~ 1.5 (亮)。
- **对比度 (Contrast) 滑块**：0.5 (低对比) ~ 1.5 (高对比)。

### 7.2 封面与书脊文字叠加 (CJK 竖排/横排)
- **书脊书名**：支持中文**竖排直书**（自上而下自动居中）与**横排旋转 90 度**。
- **封面标题 overlay**：在正面封面居中上方叠加标题，支持自定义字号 (pt)、文字颜色及自动半透明衬底 (Banner)。
- **封底简介 overlay**：在封底叠加简介、出版单位或价格等文字。

### 7.3 矢量条形码 / ISBN 自动生成
- 勾选 **“在封底右下角生成条形码/ISBN”**。
- 输入 ISBN 编号（如 `ISBN 978-7-12345-678-9`），系统将在封底右下角自动生成清晰的条形码。

## 8. ✂️ 印前标记 (角线、折痕线、镜像防白边)

### 8.1 印前裁切角线与书脊折痕
- **裁切角线 (Crop Marks)**：自动在四个外角及书脊两端绘制标准印刷裁切线（0.25pt 黑线）。
- **书脊折痕虚线 (Fold Lines)**：指示压痕机、压槽机位置。
- **版面标注信息 (Job Info)**：在纸张外边距打印装订方式、纸张规格、成品尺寸、书脊厚度及 DPI 参数，方便装订工人核对。

### 8.2 镜像自动出血 (Mirror Bleed)
若客户提供的原始图片刚好是成品尺寸、**没有预留 3mm 出血位**：
- 勾选 **“开启镜像自动出血”**，系统会自动提取原图边缘进行镜像模糊延伸填充，彻底解决切纸白边问题！

### 8.3 图片清晰度 (DPI) 智能检测
- 导入封面图片/PDF 时，系统会根据所选开本尺寸实时计算原图的**有效印刷 DPI**。
- 若有效 DPI 低于 200 DPI，界面将显示 `⚠️偏低` 警告，提醒操作员告知客户可能打印模糊。

## 9. 💾 自定义模板预设保存与调取

切换至 **【4. 自定义预设模板】** 页签：

1. **系统默认快排预设**：
   - `A5平装胶订 (A3纸拼版 / 250g铜版纸)`
   - `16开平装胶订 (A3+纸拼版 / 250g铜版纸)`
   - `A5精装硬皮包壳 (A3纸拼版 / 157g+2.0灰板)`

2. **自定义模板管理**：
   - 将常用客户或特殊规格设置好后，在“模板名称”框输入名字（如 `某某学校论文16开`），点击 **【保存当前配置为模板】**。
   - 配置文件将保存在 `user_presets/` 目录下。
   - 需要时在列表中选中，点击 **【加载选中的模板】** 即可秒级还原所有装订与纸张参数！

## 10. 📦 导出与 Windows EXE 打包发布

### 10.1 文件导出
- **导出高清图片 (PNG / JPG)**：导出 300 DPI (或所选 DPI) 高清印刷大图。

1. 双击运行根目录下的 `build_exe.bat` 脚本（或运行 `python build_exe.py`）。
2. 打包完成后，在 `dist/BookCoverGenerator/` 目录下双击 `BookCoverGenerator.exe` 即可直接运行！
